Câu Hỏi Thường Gặp (FAQ)

Hoàn toàn KHÔNG! Võ Lâm Idle là dự án phi lợi nhuận hướng tới cộng đồng yêu thích võ hiệp Võ Lâm Truyền Kỳ kinh điển. Trò chơi không có bất kỳ hệ thống nạp tiền, VIP, nạp thẻ hay quảng cáo gây gián đoạn nào. Tất cả trang bị, tính năng đều nhận được qua quá trình cày cuốc tự nhiên.

Dữ liệu được lưu trữ trực tiếp trên thiết bị của bạn (qua LocalStorage trình duyệt hoặc bộ nhớ nội bộ của app Android). Game tự động lưu sau mỗi 10 giây và có cơ chế backup slot dự phòng. Ngoài ra bạn có thể vào mục Khác → Xuất file lưu để tải về file sao lưu (JSON) dự phòng bất cứ khi nào.

Hoàn toàn được! Trên phiên bản Web bạn bấm Khác → Xuất file lưu, sau đó gửi file JSON này sang điện thoại và dùng nút Nhập file lưu trong bản Android (hoặc ngược lại). Nhân vật và hành trang sẽ được chuyển giao trọn vẹn.

Khi bạn đóng trình duyệt hoặc thoát app, nhân vật vẫn tiếp tục luyện công tại bản đồ đang đứng tối đa 8 tiếng. Khi quay lại game, bảng tổng kết sẽ hiển thị số quái đã tiêu diệt, kinh nghiệm nhận được, ngân lượng và vật phẩm rớt vào túi đồ.

OTA (Over-The-Air) cho phép game cập nhật code giao diện, tính năng mới và cân bằng môn phái tức thì mỗi khi mở app mà bạn không cần phải tải lại file cài đặt APK cồng kềnh. Gói cập nhật code thường chỉ dưới 1MB nên cực kỳ nhanh chóng và tiết kiệm 4G.

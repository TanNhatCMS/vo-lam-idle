  `${factionKey}:${sex}:${weaponCode}:${personName}:${uid-đồ}`

### 3. BXH — Bảng xếp hạng (server-side) ⭐
- **API mới**: `GET /api/rankings` (rows: rank_id UUID, name, faction,
  level, reborn, tower_best, bosses, rank, combat_power),
  `GET /api/rankings/profile`, `GET /api/chat/profile`
- Origin **không có CORS** → muốn port tab BXH thì chat-proxy.js phải
  forward thêm `/api/rankings*` (giống cách đang làm với `/api/chat/*`)
- UI: tab `BXH` trong khung chat, `world-rank-self`, profile popup
  (`showWorldChatProfile` — bấm tên nhân vật xem trang bị)

### 4. Doll / JDOLL — render nhân vật (canvas heroAvatar)
- `window.JDOLL = {res:{armor,helm,weapon,gold}, man, lady, sheets}`
- Key lookup `hd(part, item)`: `${d}:${k}:${lvl}` với d = part type
  (armor=2, helm=7, weapon=0/1), k = item code, lvl = cấp trang bị
- Có pose `nohorse`, biến thể `man`/`lady` theo sex, `DOLL_OFF` để tắt
- Dùng cho avatar header (`#heroAvatar` canvas) và hình đối thủ tỷ võ
- Nặng 1.76 MB — cân nhắc gói OTA (như bài học `img/jx`)
